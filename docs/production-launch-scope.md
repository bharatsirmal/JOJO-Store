# JOJO Store - Production Launch Scope

## INCLUDED IN V1 LAUNCH

### CUSTOMER:
- Browse products (Search, filter, category navigation)
- Register/login (Google & Email/Password)
- Add to cart and manage quantities
- Secure Checkout with authoritative server pricing
- Online payment via Stripe integration
- Order history and status tracking
- Email notifications (simulated or real via SMTP)

### ADMIN:
- Manage Products and nested Variants (Size, Color, Stock)
- Manage Categories
- Manage Inventory and stock levels
- Monitor and process Orders
- Review Payments
- Manage Shipments and assign them to delivery partners
- Review Analytics dashboard
- Approve/Promote Delivery Partners

### DELIVERY:
- Internal delivery staff authentication
- Dedicated delivery portal for assigned shipments
- Update shipment statuses (Out for Delivery, Delivered)

## EXCLUDED UNTIL LATER:
- External courier API integrations (e.g. FedEx, BlueDart)
- Automated SMS / WhatsApp messaging
- AI product recommendations
- Virtual try-on functionality
